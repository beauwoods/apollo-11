Why it can't draw a calculator

The AGC never addresses segments. It emits a 5-bit code to a relay decoder whose entire alphabet is blank plus ten digits. Type anything — letters simply have no code to send.

Scope. This shows that the software accepted unauthenticated commands and never validated the destination of an uplinked memory write. It does not show the real system was exploitable: the emulator has no RF model, and the actual defences were Deep Space Network antenna directionality, link budget, and the crew's UP TELEMETRY switch — physical, not cryptographic.

Alarm 1202 shown here is fabricated — written straight into FAILREG from the ground. The executive was never loaded and no core sets were exhausted. Alarm 1107, by contrast, is real: the computer catching its own cold start when the phase-table complement check fails.

Historical research. No AGC has flown since 1972 and the source is public domain.
